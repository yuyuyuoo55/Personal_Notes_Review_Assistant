# 个人笔记复习助手：架构与流程图

## v1.1 单 Agent 工具调用流程

```mermaid
flowchart TD
    Q[用户问题] --> M{用户选择的模式}
    M -->|快速模式 Agentic RAG| A[问答 Agent]
    A -->|无需笔记| D[直接回答]
    A -->|调用 search_personal_notes| V[向量检索 Top-3]
    V --> T[ToolMessage: 真实来源片段]
    T --> A2[Agent 基于工具结果生成回答]
    M -->|精确查找 Step RAG| P[改写 → 向量 + BM25 → RRF → Cross-Encoder → 生成]
    A2 --> S[来源 + 回答耗时]
    P --> S
```

说明：只有快速模式由 Agent 自主决定是否使用工具；精确查找是固定 Step RAG，不是第二个 Agent。

## v1 架构

```mermaid
flowchart LR
    U[学生] --> UI[Streamlit 前端]
    UI --> API[FastAPI]
    API --> INGEST[导入与切分模块]
    INGEST --> FILES[本地 Markdown / PDF 笔记]
    INGEST --> VS[(Chroma 向量库)]
    API --> REWRITE[查询改写]
    REWRITE --> RETRIEVE[混合检索工具]
    RETRIEVE --> DENSE[向量检索]
    RETRIEVE --> BM25[BM25 关键词检索]
    DENSE --> RRF[RRF 融合]
    BM25 --> RRF
    RRF --> RERANK[Cross-Encoder 精排]
    RERANK --> VS
    API --> LLM[DeepSeek 模型 API]
    LLM --> API
    API --> UI
```

## 问答流程

```mermaid
flowchart TD
    A[输入学习问题] --> B[查询改写：补全指代与关键词]
    B --> E[向量检索 + BM25]
    E --> F[RRF 融合]
    F --> G[Cross-Encoder 精排]
    G --> H{有足够相关片段?}
    H -- 否 --> I[回答：当前笔记库资料不足]
    H -- 是 --> J[片段 + 原问题组成 Prompt]
    J --> K[模型生成仅依据笔记的回答]
    K --> L[返回答案 + 文件名 + 章节 + 原文片段]
```

## 小测流程

```mermaid
flowchart TD
    A[选择笔记或章节] --> B[取该范围内的片段]
    B --> C[模型生成 3 道复习题]
    C --> D[生成参考答案]
    D --> E[每题绑定来源片段]
    E --> F[用户作答后展开答案与出处]
```

## 技术边界

| 模块 | v1 做法 | 现在不做 |
| --- | --- | --- |
| 切分 | Markdown 标题感知切分；PDF 先用普通文本切分 | 父子检索、复杂解析 |
| 检索 | 查询改写 + 向量检索 + BM25 + RRF + Cross-Encoder 精排 | RAGAS 评估、父子检索 |
| 生成 | 仅依据最终片段回答并附来源；后续可让 Agent 路由问答与小测工具 | 多轮循环、联网搜索 |
| 数据 | 本地个人笔记 | 多用户与云端同步 |
# 双模式问答架构（v1.1）

```mermaid
flowchart TD
    U[用户提问 + 模式] --> B{基础问答?}
    B -- 是 --> D[本地固定回复]
    B -- 否 --> M{模式}
    M -- 快速模式 --> V[原问题 → Chroma 向量检索 Top-3]
    V --> C[仅依据片段生成回答 + 来源]
    M -- 精确查找 --> Q[按需查询改写]
    Q --> H[向量检索 + BM25]
    H --> R[RRF 融合]
    R --> E[Cross-Encoder 精排 Top-3]
    E --> C
    V --> N{资料足够相关?}
    E --> N
    N -- 否 --> X[诚实提示：当前笔记资料不足]
    N -- 是 --> C
```

**关键边界：** 快速模式不调用查询改写、BM25、RRF 或 Cross-Encoder；精确查找才使用完整混合检索链路。

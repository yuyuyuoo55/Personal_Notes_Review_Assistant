# AI应用开发公开示例

公开合成示例，无个人笔记或隐私。正文保留既有公开测试材料的逐字内容，以复用已生成的真实向量。正文中的“本机V2”描述本机实现；Cloud使用访客独立session集合，中文分词使用维护中的fork。示例不代表学习掌握或生产可靠性。

## F01 LangGraph State、Node与Checkpointer  
State是一次图执行中由节点共享的数据。Node通常是接收State并返回更新字段的Python函数，不需要每次返回全部State。没有自定义Reducer的字段通常被新值覆盖；messages使用add_messages时按消息ID新增或更新消息，不是任何情况都简单拼接。  
Checkpointer保存按thread_id组织的图状态检查点，用于线程内连续执行、恢复和状态查看。内存Checkpointer在进程结束后不能持久保留；持久化需要相应存储实现。Checkpointer不会自动把所有线程的记忆合并。  
本机V2的build_graph最终调用builder.compile()，没有传checkpointer。API每轮根据客户端传入的history构造消息State；这属于传入聊天历史，不是已实现Checkpointer持久化。Router每轮清空旧检索结果、网页结果和回答来源，避免上一轮资料成为本轮依据。

## F02 向量检索与BM25  
向量检索先把问题和文本变成Embedding向量，再用向量距离或相似度寻找语义相关内容，可能找到措辞不同但含义接近的片段。BM25依靠分词后的词项匹配，并考虑词频、词项稀有程度和文档长度，适合关键词、术语等字面线索。两者都只召回候选，不能保证候选支持答案。  
本机V2使用DashScope text-embedding-v4和v2_notes集合。向量召回返回distance；BM25召回返回score。BM25使用pkuseg中文分词，从同一个Chroma集合读取全部片段建内存索引，不是只在向量Top3里搜索。图默认两路各取Top3。不同评分含义和量纲不能直接相加；distance也不应当作BM25的相关性分数。

## F03 RRF倒数排名融合  
RRF（Reciprocal Rank Fusion）用每条候选在各检索列表的名次融合结果。本机V2按片段ID去重，名次从1开始，默认k=60。公式为score(d)=各路命中贡献之和，每路贡献为1/(60+rank)。某一路未命中则该路贡献为0，不直接相加向量距离和BM25原始分数。  
固定例子：向量列表为A、B，BM25列表为B、C。B的分数是1/62+1/61，约0.032522；A仅有1/61，约0.016393；C仅有1/62，约0.016129。因此顺序为B、A、C。同一个ID只保留一个融合候选。融合字段包含id、content、metadata、rrf_score、vector_rank、bm25_rank。RRF不生成答案，也不保证答案事实正确。

## F04 Cross Encoder重排  
Cross Encoder把问题与每条候选正文组成一对，联合编码后输出相关性分数；与独立编码问题和文档的向量召回不同。它用于候选集合内的精细排序，不负责生成回答，也不能找回未进入候选集合的文档。  
本机V2把RRF候选传入本地BAAI/bge-reranker-base，predict逐对打分，再按rerank_score降序保留Top3。输入候选被复制，RRF排名字段仍保留。空候选直接返回空列表，不加载模型。首次缓存缺失可能下载模型；本地推理不调用付费生成API。当前没有通过rerank_score设置拒答阈值，低相关候选存在时仍需要回答模型判断依据是否不足。

## F05 FastAPI SSE事件  
SSE用text/event-stream响应体发送事件帧，事件可含event和data字段，空行结束一帧。HTTP 200只说明流响应建立，不说明整个业务成功。  
本机V2的POST /chat/stream发送status、token、sources、done、error五类事件。status表示处理阶段及节点完成；token是模型增量文字，在done前属于未完成草稿；sources是本轮最终实际引用的来源；done带completed状态、完整answer和route；error表示未完成，前端应丢弃本轮草稿。引用编号校验通过后才发送sources和done。发生error或流提前断开不能当成问答通过。原始SSE能看到节点顺序，但不会直接输出全部检索候选或RRF分数。

## F06 RAG来源引用与无资料拒答  
本机V2的笔记回答只允许依据本轮提供的精排笔记和允许使用的网页。本地引用用[1]等数字编号，网页引用用[W1]等W编号。最终来源列表只保留答案实际引用的候选。非法编号会报错；合法编号只证明编号对应候选，不证明结论忠实，需要人工核对正文。  
笔记和可用网页均为空时程序直接拒答，不调用回答模型。有候选但候选不能支持核心答案时，回答Prompt要求首行“当前笔记库资料不足。”，说明缺少的依据，不用模型常识补造。历史回答不是本轮知识依据。联网关闭时不调用网页搜索。

# V2 前端

在仓库根目录运行 `python v2/start_local.py` 或双击 `start_v2.bat`，同时启动本机 FastAPI 与 Streamlit。完整 Python 3.12 依赖安装和配置见 [V2 README](../README.md)。启动时生成随机设置令牌，只通过子进程环境传递，浏览器不接收令牌。

- 智能问答：SSE Token 真增量，只有 `done` 后保存完整助手回答。普通聊天与通用查询属于 daily，个人笔记问答属于 knowledge；联网关闭不搜索，开启后日常按需搜索、笔记可补充网页。
- 知识库：Markdown、单图、图文 ZIP；展示实际导入、重复、部分成功和失败状态。
- 章节小测：整篇或指定章节，0～5 选择题、0～3 问答题，总数至少一题。翻题保留草稿，提交锁定答案。
- 学习报告：实际错误与潜在混淆分别展示，保留真实题量、批改结果和复习建议。
- 设置：DeepSeek / DashScope 的脱敏配置状态，用户主动同意费用后验证保存，失败保留原配置，删除需确认；余额主动查询，无自动刷新。

聊天和草稿存在 Streamlit 会话中，刷新不保证保留。后端 QuizStore 是进程内存储，重启后小测/报告失效，前端通过 instance_id 清理过期状态。单用户 / 单 worker / loopback 限制不变，不支持直接将本机设置 API 公开到互联网。

假引用、模型失败、协议错误或流中断不保存本轮草稿；联网失败明确提示。关闭开关或改问日常问题后，不展示上一轮引用。

离线和可选浏览器验证命令见 [V2 README](../README.md#离线回归)，公开验证摘要见 [发布验证](../RELEASE_VALIDATION.md)。原始本机验收日志与数据库不随源码发布。

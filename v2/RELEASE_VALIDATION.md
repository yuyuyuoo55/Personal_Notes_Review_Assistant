## 修复行为

- 保留 daily / knowledge 两种 Router 结果，增加 requires_web 标记。
- daily 包含普通聊天、稳定知识与通用信息查询；明确依赖个人笔记及对应追问才走 knowledge。
- 开关关闭时任何路径都不搜索。开启时 daily 仅在实时信息或明确搜索需求下搜索，knowledge 在原 RAG 后补充网页。
- 复用 query_rewrite / Tavily MCP / web_results，不重复创建搜索客户端。
- 每轮清理检索状态和来源；网页、笔记编号分开，只展示当前答案实际引用的资料。
- 日常联网回答复用真实 Token 适配器和来源校验；网页无引用、非法编号或模型错误发 error，不发成功 done。
- 实时问题未联网、搜索失败或无可用结果明确说明无法确认实时信息。普通日常问题不显示笔记库资料不足。
- 代码块和行内代码中的列表/索引不视为引用。

# 个人笔记复习助手

面向学生的本地学习工具：导入个人 Markdown 笔记后，用自然语言提问即可获得**带原文来源**的回答；笔记库没有依据时明确拒答，不编造答案。

## 已实现能力

- **笔记导入**：上传 `.md` 文件，按 Markdown 标题层级切分，生成稳定 `chunk_id` 并写入 Chroma；完成空文件、重复文件与格式校验。
- **双检索模式**：
  - 快速模式（Agentic RAG）：问答 Agent 自主判断是否调用笔记检索工具，适合日常复习与指代追问，响应快。
  - 精确查找（Step RAG）：固定链路「查询改写 → 向量检索 + BM25 双路召回 → RRF 融合 → Cross-Encoder 精排 → 带来源生成」，适合术语与需要可靠来源的问题。
- **查询改写**：针对「它、这个、刚才」等指代型问题补全检索词，改写失败自动回退原问题。
- **资料不足拒答**：检索结果不足时明确提示「当前笔记库资料不足」，不强行编造答案。
- **流式交互**：SSE 分段返回回答、来源片段与耗时，前端展示检索模式与阶段进度。
- **会话记忆**：快速模式支持「最近 3 轮原文 + 异步摘要」的进程内短期记忆。

> 章节小测为规划中功能，暂未开放。

## 本地启动

### 双击启动（推荐）

双击项目根目录的 `启动项目.cmd`。它会启动前后端，并自动打开前端页面。

运行日志在 `logs/backend.log` 和 `logs/frontend.log`。关闭服务时，在任务栏或任务管理器结束对应终端进程；开发阶段也可继续使用下面的手动启动方式查看实时日志。

### 手动启动

```powershell
uv sync
uv run uvicorn backend.app.main:app --reload --port 8000
```

另开一个 PowerShell：

```powershell
uv run streamlit run frontend/app.py
```

- API 文档：`http://127.0.0.1:8000/docs`
- 前端页面：终端输出的本地地址，通常为 `http://localhost:8501`

## 当前接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/health` | 健康检查 |
| GET | `/api/notes` | 已导入笔记列表（含片段数） |
| POST | `/api/notes/import` | 上传 `.md` 笔记（multipart 表单，字段名 `file`） |
| POST | `/api/chat` | 问答（SSE 流式；body：`{"query", "mode": "fast"\|"accurate", "conversation_id"}`） |

## 安全

- `.env` 只留在本机，绝不提交。
- 不要将真实 API Key、个人笔记中的隐私信息写入 README、日志或截图。
- 两种模式都不会联网补充知识；无可靠资料时返回「当前笔记库资料不足」，而不是编造答案。

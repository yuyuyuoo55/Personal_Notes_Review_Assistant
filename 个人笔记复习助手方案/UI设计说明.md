# UI 设计说明

## 页面结构

- 左侧栏：笔记库、导入按钮、最近学习记录。
- 主区域顶部：当前笔记库名称和检索范围。
- 中间：问题输入框、回答卡片、来源引用卡片。
- 右侧：切换到“章节小测”，生成三道题并展开答案。

## 视觉方向

- 轻量、安静的学习工具，不做科技感大屏。
- 米白背景、深蓝文字、低饱和绿色作为完成/引用提示色。
- 信息优先：回答和原文出处比装饰更醒目。

## 核心交互

1. 点击“导入笔记”，显示文件与处理状态。
2. 提问后，先看到简洁答案，再展开“参考笔记”。
3. 点击“来一组小测”，围绕当前笔记生成 3 题。
4. 用户自行作答后点击“查看参考答案”，同时显示出处。
# v1.1 双模式 UI 说明

选用的页面结构是在问答区顶部放置两个并列模式按钮，输入框始终位于独立滚动的聊天历史下方：

- **快速模式**：突出“仅向量检索 · 更快”，默认选中。
- **精确查找**：突出“改写 + 双路检索 + 精排 · 更准”。
- 按钮下方立即显示当前链路，用户切换时可直观看到取舍。
- 右侧复习卡同步显示当前模式、适用场景和限制。
- 只有中间聊天历史容器滚动；侧边栏、顶部和右侧信息保持固定布局。

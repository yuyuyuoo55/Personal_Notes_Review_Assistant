# 个人笔记复习助手：开发顺序与分工

## 分工

| 范围 | 负责人 | 说明 |
| --- | --- | --- |
| RAG 主链路的理解、参数与面试复述 | 小余 | 每完成一个模块，只需能说明“解决什么问题、输入输出是什么、为什么这样选” |
| 前端 UI、页面交互、视觉样式、前后端联调 | Codex | 小余不需要学习前端实现，只在验收节点体验 |
| 后端与 RAG 代码 | 小余主导，Codex 按模块协助 | 保持每一步可运行、可解释；不一次性堆完整代码 |
| 验收 | 小余 | 按验收场景实际操作，反馈是否好用和是否符合预期 |

## 开发总原则

先让核心链路在命令行稳定，再固定 API，最后由 Codex 接管前端。这样 UI 不会被未定的检索逻辑拖着返工。

## 开发顺序

### 第 0 步：冻结演示资料与问题（半天）

- 选 3 份真实 Markdown 笔记作为首批资料，例如 RAG 学习笔记、Java 面试笔记、数据库笔记。
- 写 10 个已知答案的问题：术语问题、概念对比、跨章节问题、笔记外问题。
- **验收**：每题都能指出预期来自哪份笔记或应当拒答。

### 第 1 步：笔记入库与基础检索（第 1 天）

- 导入 Markdown，按标题切分，保留文件名、标题路径、片段 ID。
- 建立 Chroma 向量索引；命令行输出向量 Top-K 结果。
- **验收**：导入 3 份笔记后，任意问题能看到来源片段。

### 第 2 步：查询优化与混合检索（第 2 天）

- 加查询改写；失败时使用原问题。
- 增加 BM25、RRF 和 Cross-Encoder 精排。
- 命令行打印“原问题、改写后问题、向量结果、BM25 结果、最终精排结果”。
- **验收**：小余能用一个真实例子说明四步分别解决什么问题。

### 第 3 步：带来源回答与拒答（第 3 天）

- 使用最终片段组织 Prompt，限制模型只依据笔记回答。
- 返回答案、来源文件、章节、原文预览；无可靠片段时拒答。
- **验收**：回答能回到原文；笔记外问题不编造。

### 第 4 步：固定 FastAPI 接口（第 4 天）

前端只依赖以下稳定接口：

| 接口 | 用途 | 关键返回 |
| --- | --- | --- |
| `POST /api/notes/import` | 导入本地笔记 | 文件名、分块数、处理状态 |
| `GET /api/notes` | 获取笔记列表 | 笔记 ID、名称、分块数 |
| `POST /api/chat` | 问笔记 | 答案、改写后问题、来源列表、是否拒答 |
| `POST /api/quiz` | 生成章节小测（有时间再做） | 题目、选项、答案、来源 |

- **验收**：用接口调试页完成导入、问答和拒答三种场景。

### 第 5 步：Codex 接管前端（第 5—6 天）

Codex 完成 Streamlit 前端：

1. 笔记库侧栏：导入、处理状态、笔记列表。
2. 问答主区：问题输入、加载状态、答案、来源卡片、资料不足提示。
3. 检索透明信息：默认折叠展示“改写后的查询”和最终来源；不暴露冗长调试日志。
4. 小测页：仅在后端接口完成后接入。

- **验收**：小余不看代码，按“导入 → 提问 → 看来源 → 问笔记外问题”完整走一遍；界面与最初 UI 图的整体感觉一致。

### 第 6 步：单 Agent 路由（第 7 天，有余力才做）

- 仅在“问答”和“小测”两个工具间做路由。
- 不影响已完成的固定检索问答；Agent 失败时前端仍可直接进入问答模式。
- **验收**：输入“帮我考一下 RRF”会进入小测；输入知识问题会进入带来源问答。

### 第 7 步：演示与面试材料（第 7 天末）

- Codex 整理 README、架构图、运行说明和演示操作顺序。
- 小余完成 10 题验证表，准备 3 分钟讲解。
- **验收**：从启动到演示结束不超过 3 分钟，所有结论能在笔记或记录中找到依据。

## Codex 前端验收清单

- [ ] 笔记导入后能看到成功/失败状态，不会无提示卡住。
- [ ] 回答区优先展示结论，来源默认可展开查看。
- [ ] 资料不足时有清楚提示，不伪装成正常回答。
- [ ] 手机宽度下内容不遮挡；桌面端三栏结构清晰。
- [ ] 不在页面、日志或仓库中显示 API Key、Token 等敏感信息。
# 双模式开发与验收

新增一个小阶段：在已有 `/api/chat` 上增加 `mode` DTO 字段、RAG 服务分流和前端模式选择，不新建第二套接口。

验收由小余操作：

1. 选快速模式，确认问题直接走向量检索并能展示来源。
2. 选精确查找，确认术语问题可走查询改写、BM25、RRF、精排。
3. 用笔记外问题验证两种模式都会诚实提示资料不足。
4. 用“你好，你是谁”验证基础问答不会检索数据库。
